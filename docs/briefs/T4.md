## Tugas
1. `scripts/import-quran.ts`: unduh teks Uthmani dari tanzil.net (ikuti halaman download resmi; baca dan simpan teks lisensi Tanzil apa adanya). Ambil hanya surah 18, 36, 55, 56, 67 dan 65:2-3. Simpan ke `content/quran/uthmani.json` (surah, ayat, teks persis byte-per-byte dari sumber), `content/quran/SOURCE.md` (URL, tanggal unduh, versi, SHA-256 file sumber utuh, teks lisensi, atribusi). Script bisa dijalankan ulang dan memverifikasi checksum.
2. Jika format atau URL Tanzil berbeda dari dugaan, baca halaman download dulu; jangan menebak. Jika gagal unduh: BERHENTI, laporkan. JANGAN mengetik atau menghasilkan teks ayat dari ingatan, dan jangan mengambil dari sumber lain (termasuk repo GitHub pihak ketiga) tanpa persetujuan owner.
3. Test QURAN-01: jumlah ayat 110 (18), 83 (36), 78 (55), 96 (56), 30 (67), 2 (65:2-3); SHA-256 file sumber cocok dengan SOURCE.md; teks di JSON identik dengan teks di file sumber untuk setiap ayat yang diambil.
4. `src/server/prayer/`: interface `PrayerTimeProvider`, `SihatProvider` (baca token dari env; tanpa token gagal dengan error `PROVIDER_NOT_CONFIGURED`, jangan menebak URL API), cache per region per bulan, label sumber (provider/cached/manual). Test PRAYER-01, PRAYER-02 di level adapter dengan provider palsu.
5. `src/server/push/`: pengirim Web Push (VAPID dari env, kunci dev dibuat oleh test, tidak di-commit), payload notifikasi, penanganan 404/410 → subscription nonaktif, 429/5xx → retry. Test dengan server HTTP palsu.
