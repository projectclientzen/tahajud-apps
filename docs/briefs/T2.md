## Tugas
1. Label status baru "Sedang berjalan" untuk `in_progress` (keputusan owner): tambahkan ke `src/domain/content/session-status.ts` tanpa menghapus ekspor yang ada; StatusChip memakai ikon yang berbeda dari status lain.
2. `/quran` + `/quran/[surah]`: daftar 6 bacaan (PRD §13.1), reader RTL dengan penanda ayat, kontrol ukuran font (22-44px), bookmark, ayat terakhir, progress, tombol selesai, mode malam, badge "Bacaan Jumat" sesuai jendela Al-Kahfi dari domain. TANPA teks ayat: selama dataset belum diimport (T4), reader menampilkan state "Dataset Al-Qur'an belum diimport" dan kontrol progress tetap bisa diuji dengan fixture uji yang jelas bukan Qur'an (mis. teks "Ayat uji 1") hanya di test.
3. `/reports` (7/30/90, status counts, completion rate, statistik per amalan, insight) dan `/reports/calendar` (bulan penuh, navigasi bulan, detail sesi). Penyebut 0 → "Belum ada data".
4. `/settings`: tema, ukuran font Arab (Qur'an dan dzikir), durasi ibadah per level, buffer, target tidur, preferensi notifikasi + quiet hours, wilayah/jadwal manual (pakai `profile.setLocation` lewat hooks yang ada; jika hook belum ada, tulis permintaan ke orchestrator, jangan ubah `src/components/providers/**`). `/settings/devices` (daftar perangkat, keluarkan perangkat lain; batas 3) dan `/settings/account` (unduh data JSON, hapus akun dengan konfirmasi ketik ulang email).
5. `/notifications`: riwayat notifikasi (mock), state "push tidak didukung" dengan panduan alarm manual (NOTIF-03), iOS belum install → panduan install.
6. `/help`: referensi amalan (sumber dari `content/amalan.v1.json`, tanpa klasifikasi karangan), disclaimer "syarat aplikasi bukan hukum fikih", kontak CS (env `NEXT_PUBLIC_CS_WHATSAPP`, kosong = sembunyikan), kebijakan privasi placeholder berlabel draft.
7. `/profile`: ringkasan akun + link ke settings, devices, account, help.
