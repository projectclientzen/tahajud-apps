Block 1 (Hard Gate), semua "tidak" setelah perbaikan:
- R-02 em dash: grep di `src`, `README.md`, `docs/SITEMAP.md`, `docs/DESIGN_SYSTEM.md` kosong. `--` di Mermaid adalah sintaks panah, bukan teks UI.
- R-03 mobile: e2e 320px tanpa horizontal scroll; tap target nav 44px diuji.
- R-17/18/36/38: tidak ada statistik, testimoni, klaim. Angka gallery berlabel contoh.

- R-25: kontras lolos, 49 unit test + axe 0 serious/critical. Temuan 1 diperbaiki di sini.
- R-26: link halaman masuk dan nav bekerja (e2e). Tombol gallery adalah specimen berlabel.
- R-27: komponen Empty, Error, Skeleton ada. Layar berdata belum ada (S3).
- R-28: tidak ada FAQ.
- R-32: Tab dan fokus terlihat; Sheet tertutup dengan Escape (e2e).
- R-33: tidak ada script patch.
- R-34: light dan dark sama-sama diuji (axe dan screenshot).
- R-35: build dan e2e dijalankan. Click-through: nav 4 link, "Buka prototipe" -> `/dashboard`, toggle tema -> `data-theme` tersimpan setelah reload, "Buka sheet" -> dialog, Escape -> tertutup; 0 console error di 6 route.

Block 2 (Purpose-Gate): R-04 dan R-14 alasan tertulis (A4 dan komponen berbeda per makna). R-09: badge hanya untuk status nyata (Data demo, status sesi). Tanpa gradient, glow, glass, grid, atau ilustrasi.
