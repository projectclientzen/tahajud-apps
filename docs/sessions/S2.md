## Yang dikerjakan

- Config provisional (`src/domain/config/provisional.ts`), semua nilai `provisional: true`, diuji dengan snapshot.
- Loader konten bertipe + snapshot sesi (level, zona, wilayah, versi konten dibekukan).
- Session key, cutoff, jendela koreksi, state machine, status otomatis.
- Kalender (missed derived), berhalangan satu tanggal dan rentang (maks 15 hari), pembatalan dalam jendela koreksi.
- Progression: progress per level dari snapshot, unlock efektif sesi berikutnya, level monoton, milestone Level 3.
- Reporting: status counts, completion rate (null jika penyebut 0), filter 7/30/90, statistik per amalan, 5 insight.
- Dzikir: reducer klien (coalesce 2 detik / target / hidden, ack, `set_zero`, tidak negatif) dan `applyOperation`/`applyBatch` server (idempoten per user+operation_id, clamp jam klien 5 menit, tolak di luar jendela koreksi).
- Prayer: planner bangun + peringatan tidur, jendela Al-Kahfi (fallback 18.00), pemilihan sumber jadwal (provider / tersimpan / manual).
- Notifikasi: rotasi bedtime, dedupe key, kedaluwarsa per tipe, quiet hours, whitelist variabel template.
- Data layer: kontrak Zod, interface repository, mock engine, 7 skenario, time travel, `createDataLayer` memilih mode dari `NEXT_PUBLIC_DATA_MODE`.
- Test penjaga: `tests/unit/domain/purity.test.ts` (tidak ada import React/Next, tidak ada `Date.now()` / `new Date()` tanpa argumen di `src/domain`).

## Aturan yang BUKAN dari PRD (karangan agen, perlu persetujuan)

Insight di `src/domain/reporting/insight.ts`. PRD §22.4 hanya menyebut 5 jenis, tanpa ambang. Ambang ini milik saya:

- `first_completion`: satu-satunya sesi tuntas, dalam 7 hari terakhir.
- `return_after_gap`: sesi tuntas/sebagian terbaru (≤ 2 hari) didahului ≥ 3 malam terlewat berturut-turut (berhalangan dilewati).
- `milestone_progress`: tepat di setengah target atau satu sesi lagi.
- `improvement`: tingkat tuntas 7 sesi terakhir naik ≥ 15 poin dari 7 sesi sebelumnya.
- `stable_consistency`: ≥ 5 dari 7 sesi terakhir tuntas.
  Teks template juga tulisan saya. Perlu dibaca owner (tanpa skor, tanpa ranking, tanpa shaming).
