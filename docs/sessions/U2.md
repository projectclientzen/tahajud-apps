## Bug yang ditemukan tes dan diperbaiki
- "Tandai sampai halaman 604" dari posisi 0 menghasilkan posisi 0 (kandidat `k = -1`). Ditemukan `khatam-api.test.ts`, diperbaiki di `positionAfterMark` dan SQL `mark_khatam_position`, ditambah tes unit.
- Build gagal karena `modeLimit` diimpor dari berkas "use client" ke rute server. Dipindah ke `read-modes.ts`.

## Penyimpangan dari brief (dan alasannya)
1. Kota terdekat memakai `content/regions/crosscheck-coordinates.json`, bukan `wikidata-coordinates.json`. File crosscheck adalah turunan file Wikidata yang sudah cocok ke nama EQuran (keputusan U2-1).
2. Enam bacaan malam tetap ada di tab Al-Qur'an (dilipat) karena sesi malam belum punya tautan ke sana (U2-9).
3. `Region.place` opsional ditambah ke kontrak untuk memetakan kota ke wilayah (tidak mengubah SQL).
4. Skrip impor menulis `public/quran/` dan `content/quran/meta.json`; SOURCE.md diperluas.

## Belum diuji atau belum dikerjakan
- Migration khatam hanya dijalankan di PGlite, belum di PostgreSQL/Supabase nyata (Docker tidak ada).
- E2E live (HTTP + PGlite) untuk khatam dan lokasi otomatis belum ditulis. Rute HTTP diuji lewat `api-khatam.test.ts`.
- Data khatam belum masuk `/me/data-export` (`src/server/api/account.ts` di luar kepemilikan sesi ini).
- Tabel `regions` live masih 3 wilayah demo. Lokasi otomatis di live baru bekerja penuh setelah 517 wilayah EQuran diimpor ke tabel itu.
- Batas halaman dari metadata Tanzil belum dibandingkan dengan mushaf cetak. Font Amiri Quran belum diuji visual di surah panjang (Al-Baqarah).
- Wake Lock, geolokasi di perangkat nyata (iOS Safari PWA), dan antrean offline khatam di perangkat nyata belum diuji.
- Dokumen lain yang masih menyebut "Tahajud Tracker" (PRD, README, CLAUDE.md, docs lama) tidak diubah: di luar kepemilikan sesi.
